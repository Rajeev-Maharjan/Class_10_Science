About

We use a simplified proportional model: F ∝ (m1 * m2) / d2. This page shows the relative force when you change masses and distance. The visualization uses circle sizes to represent masses and a connecting "rope" whose thickness represents force.

Full Calculation (including G)

This section shows the full numeric calculation using Newton's law: F = G * (m1 * m2) / d2. For clarity we treat slider values as kilograms (kg) for masses and meters (m) for distance.
