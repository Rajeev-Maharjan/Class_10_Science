Gravity Variable Lab — Interactive website

Files:
- index.html  — main interactive page
- styles.css  — page styling
- script.js   — interactive logic (sliders, visualization)

How to use:
1. Open `d:\Share market\InteractiveGravity\index.html` in your browser (double-click or right-click -> Open with).
2. Use the sliders to change m1, m2, d. The visualization updates and the calculated relative force F (proportional) is displayed.
3. Use buttons to quickly test the classroom cases: doubling masses or changing distance.

Notes for teachers:
- This is a proportional model: F shown = (m1 * m2) / d^2 (no G constant, no units).
- The visualization is qualitative and intended to help students reason about proportional changes.
